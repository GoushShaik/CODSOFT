# Rule-Based Chatbot

## CodSoft AI Internship - Task 1

### Description

This project is a Rule-Based Chatbot developed using Python.

The chatbot interacts with users through predefined commands and responses.

### Features

- Personalized user name
- Greetings
- Help menu
- AI information
- Machine Learning information
- Python information
- Motivation messages
- Study tips
- Joke feature
- Current time display
- Basic calculator
- Exit command

### Technologies Used

- Python 3

### How to Run

1. Open terminal
2. Navigate to project folder
3. Run:

```bash
python chatbot.py
```
