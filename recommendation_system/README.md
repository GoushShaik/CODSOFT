# Recommendation System

## CodSoft AI Internship - Task 4

This project is a scoring-based recommendation system developed using Python. It recommends Movies, Books, Music, and Games based on user-selected categories and genres. The system also tracks user preferences during the session to provide more relevant suggestions.

---

## Features

- Command-line based user interaction
- Category selection (Movies, Books, Music, Games)
- Genre-based filtering within each category
- Session-based preference tracking
- Simple scoring system for recommendations
- Surprise option for random recommendations
- Continuous interaction until user chooses to exit
- Basic personalized feedback based on user activity

---

## Technologies Used

- Python 3
- Built-in modules only (random)

---

## How It Works

1. User enters their name
2. System displays available categories
3. User selects a category
4. System shows available genres for that category
5. User selects a genre or surprise option
6. System displays recommended items
7. System tracks user choices during the session
8. System provides basic feedback based on repeated preferences
