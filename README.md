## Tasks Completed

### Task 1 - Rule-Based Chatbot

**Folder:** task1_chatbot/

A rule-based chatbot that responds to user inputs using predefined patterns and conditions.

**Features:**
- Handles greetings, basic conversation, jokes, time, help, and calculator functions
- User name personalization
- Command-based interaction system
- Fallback responses for unknown inputs

**How to run:**
cd chatbot
python chatbot.py

---

### Task 2 - Recommendation System

**Folder:** recommendation_system/

A scoring-based recommendation system that suggests Movies, Books, Music, and Games based on user-selected categories and genres. The system tracks user preferences during the session and uses that to slightly improve recommendations.

**Features:**

* Category selection (Movies, Books, Music, Games)
* Genre-based filtering
* Session-based preference tracking
* Simple scoring system based on user choices
* Surprise option for random recommendations
* Interactive loop until user exits

**How to run:**

cd recommendation_system
python recommendation_system.py

---

### Task 3 - Tic-Tac-Toe AI

**Folder:**  tic_tac_toe/

A Tic-Tac-Toe game where the user plays against an AI. The AI uses the Minimax algorithm to decide the best move.

**Features:**

* Human vs AI gameplay
* Minimax algorithm implementation
* Win and draw detection
* Input validation
* Replay option

**How to run:**

cd tic_tac_toe
python tic_tac_toe.py
