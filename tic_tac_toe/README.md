# Tic-Tac-Toe AI

## CodSoft Internship - Task 2

A Tic-Tac-Toe game built using Python where the user plays against an AI powered by the Minimax Algorithm.

## Features

- Human vs AI gameplay
- Minimax Algorithm
- Win Detection
- Draw Detection
- Input Validation
- Replay Option

## Technologies Used

- Python 3

## How to Run

1. Open terminal
2. Navigate to project folder
3. Run:

python tic_tac_toe.py
